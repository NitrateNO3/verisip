# VeriSip — proposal website

A one-page site presenting VeriSip, an app (in development) for verified, licensed and fully traceable home delivery of liquor, written for state Excise, Transport and Police departments.

Built with React + Vite and framer-motion.

## Run locally

```bash
npm install
npm run dev
```

Production build: `npm run build` (output in `dist/`).

## Editing

- Brand name, contact email and phone: `src/config.js`
- Each section is a component in `src/components/` with its own stylesheet in `src/styles/`
- Photos live in `public/images/` (from Unsplash)

All dashboard figures, shop names and licence numbers on the site are sample data.
